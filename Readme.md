# Sistema de Gerenciamento em Java

## Descrição

Este projeto foi desenvolvido como trabalho acadêmico para a disciplina de Programação Orientada a Objetos da faculdade.

O sistema foi criado utilizando a linguagem Java e tem como objetivo simular um sistema de gerenciamento envolvendo:

- Usuários
- Fornecedores
- Produtos
- Transportadoras

O projeto utiliza conceitos fundamentais de Programação Orientada a Objetos (POO), incluindo:

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Manipulação de ArrayList
- HashMap
- Métodos de CRUD
- Organização de entidades

---

# Funcionalidades

## Usuários
- Cadastro de usuários
- Alteração de usuários
- Exclusão de usuários
- Consulta por ID
- Sistema simples de login

## Produtos
- Cadastro de produtos
- Alteração de produtos
- Exclusão de produtos
- Consulta de produtos por ID

## Fornecedores
- Cadastro de fornecedores
- Alteração de fornecedores
- Exclusão de fornecedores
- Associação de produtos aos fornecedores

## Transportadoras
- Cadastro de transportadoras
- Alteração de transportadoras
- Exclusão de transportadoras
- Controle de produtos transportados

    - HashMap
